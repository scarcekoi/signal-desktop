## Usage

> [!WARNING]
> Windows theme is not 100% reliable and might not work for you.

1. Download the flavor of your choice.
2. Open the app and go to **Preferences** > **Appearance** > **Import theme**.
3. Select the downloaded flavor file.
4. Enjoy!
